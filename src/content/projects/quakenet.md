Course project for CSE421: Computer Networks at BRAC University. QuakeNet is a
Cisco Packet Tracer network design intended to support earthquake monitoring,
emergency communication and disaster response.

The topology brings together VLSM subnetting, DHCP and DHCP relay, RIPv2,
static routing, route failover, DNS, web services, email communication and
network redundancy. The repository includes the Packet Tracer project file for
inspection; this is a network-design project, not a deployed emergency alert
service.
